# 量子雷达 · 回声侦探

简体中文 H5 量子照明科普游戏。通过制备探测信号、保存参考、接收含噪回波和联合测量，体验从观测中积累目标证据的过程。

网站使用 Phaser 3.90.0，全部脚本和运行素材位于 `dist/`。游戏在浏览器内运行，无需后端服务、API 密钥或第三方字体服务。

## 本地运行

安装 Node.js 24，在仓库目录运行：

```sh
npm run dev
```

打开 `http://127.0.0.1:4173`。主页为三关寻踪游戏，发现手册中可以进入完整的八步实验台。ES 模块需要通过 HTTP 加载。

## 在 GitHub Pages 上发布

1. 创建公开仓库，默认分支使用 `main`，将本目录的内容推送到仓库根目录。保留 `.github/workflows/pages.yml`。
2. 在仓库的 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**。
3. 推送到 `main`，或在 **Actions → Publish quantum echo game → Run workflow** 中手动启动。
4. 工作流检查脚本语法和教学模型后，将 `dist/` 发布到 GitHub Pages。成功运行的部署步骤会显示实际访问地址。

后续推送到 `main` 会自动更新网页。项目使用相对资源路径，可在 `https://<账号>.github.io/<仓库名>/` 下运行。

GitHub 官方说明：[配置发布来源](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。


运行库已包含在 `dist/vendor/`，当前检查和发布流程无需安装 npm 依赖。`package.json` 与锁文件保留 Phaser 版本信息。

## 操作

- 开场教学依次介绍两路光的制备、参考保存、目标回波、噪声和联合接收，可选择跳过。
- 三关游戏每关提供 12 次探测，背景噪声逐关增加。
- 支持鼠标、触屏和键盘：左右方向键选择区域，空格发射或接收，Tab 访问按钮。
- 提供暂停、重试、星级、可选合成音效和发现手册，并尊重减少动态效果设置。

## 科学范围

本作品用于交互科普。三岛寻踪与八步实验台采用高斯统计教学模型，交互参数不作为实际雷达性能预测或论文实验复现。

开场源关联视图按理想双模压缩真空态的理论关系绘制，关联条表示特定相敏交叉关联的幅度。视图不执行真实量子测量，关联条不表示探测成功率。

联合接收教学采用理想相位共轭接收器：处理来波后，与尚未单独测量的参考在均匀分束器中干涉，探测两个出口并累积光子计数差。每组使用 1024 对全新模式，假设无损参考保存、稳定且已补偿的传播相位、独立热背景和理想探测器。模型包含相位共轭所需的真空噪声。正确与错配参考的对照保持各路平均亮度；这一对照本身不能验证量子优势。

各教学模型的用途、假设、参数和文献在网页的“科学依据”及可展开详情中说明。模型测试检查统计关系和程序行为，不等同于真实量子实验验证。正式参赛所需的科学审核、公开刊发认定及证明应按活动要求办理。
